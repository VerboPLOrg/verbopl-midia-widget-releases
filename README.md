# Chamada Verbo PL — Distribuição

Este repositório **não contém código-fonte**. Ele existe apenas como canal público
de distribuição do aplicativo **Chamada Verbo PL**, usado pelo Departamento da Mídia
da Verbo Pedro Leopoldo.

O código-fonte é mantido em repositório privado da organização.

## Instalar

Baixe o instalador mais recente em **[Releases](../../releases/latest)** e execute.

## Atualizações

O aplicativo verifica automaticamente se há uma versão nova toda vez que é aberto.
Havendo atualização, ele pergunta antes de baixar e instalar — não é necessário
baixar nada manualmente depois da primeira instalação.
